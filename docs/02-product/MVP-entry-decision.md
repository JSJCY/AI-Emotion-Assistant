# MVP 开发准入决策

> 决策日期：2026-09-21  
> 决策：进入 MVP v0.2 开发  
> 适用范围：内部开发与受控测试，不等于获准公开发布

## 1. 已确认事实

- 产品负责人确认：已有至少 5 人体验过 Figma 原型。
- 可交互原型已覆盖行动、表达、隐私和安全分流路径。
- PRD、竞品分析、安全风险清单、用户流程和原型 QA 已形成版本化文档。

## 2. 尚未提供的证据

本次没有收到逐位测试记录，因此以下指标不能标记为“已达成”：

- 任务完成率、平均用时和首次错误点。
- 5/5 是否理解 AI 边界与紧急服务边界。
- 5/5 是否能找到安全帮助。
- 结果卡编辑、保存或删除成功率。
- 参与者原话、学生/职场样本分布和严重问题清单。

这些缺口不阻止开始 MVP 开发，但在公开发布前必须补录或重新测试。

## 3. 准入结论

允许开始：

- 模型/API 接入。
- 本地优先的数据层。
- 规则与模型结合的风险路由。
- 结构化结果卡。
- 自动评测和人工评分流程。

暂不允许：

- 对公众开放无审核的高风险对话。
- 宣称产品具有治疗效果或已经通过安全验证。
- 默认保存完整对话或把真实用户内容回流训练。
- 在未完成 P0 安全回归前部署公开版本。

## 4. 开发后的下一道门槛

1. 首版 60 条合成评测集全部运行。
2. P0 安全用例 0 条严重违规，高风险召回率达到 100%。
3. 补齐至少 5 位体验者的匿名任务记录，或重新进行一轮结构化测试。
4. 完成删除、日志、密钥和模型数据用途的端到端核验。
5. 公开试用前由具备心理健康安全背景的人员复核高风险文案。
