- 评测 runner 支持指定案例回归，并分开报告 Schema、输出审计、高风险召回、L0 危机误升级和红队结果。

## 2. 模型选择结论

早期方案使用 Flash 做风险分类、Plus 做生成。真实定向对照显示 Flash 在持续困扰、依赖边界和信号码一致性上更不稳定；Plus 虽有更高延迟与成本，但在安全敏感 MVP 中更合适。

最终固定：

```text
risk_model=qwen3.7-plus-2026-05-26
generation_model=qwen3.7-plus-2026-05-26
enable_thinking=false
generation_temperature=0
response_format=json_schema(strict=true)
```

两个职责仍保持独立请求、独立 Prompt、独立 Schema 和独立后置校验。
