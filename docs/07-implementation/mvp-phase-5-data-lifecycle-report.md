# MVP Phase 5 服务端数据生命周期报告

> 日期：2026-09-22
> 状态：服务端实现与自动门禁通过；端到端浏览器与备份验收待完成

## 1. 本阶段目标

在不保存用户消息、历史上下文、Prompt 或模型回复正文的前提下，完成服务端最小事件存储、匿名导出、删除回执和日志脱敏。

## 2. 实现内容

- 使用 Node.js `node:sqlite` 实现单实例 SQLite 事件仓库。
- 启用 WAL、外键、忙等待和版本化迁移；数据库与目录按配置创建。
- `/ready` 在每次请求时真实探测事件存储，不再使用固定占位状态。
- `x-anonymous-id` 只接受 UUID；服务端仅保存 SHA-256 哈希。
- `GET /api/v1/events/export` 导出请求、风险、路由、动作、模型/策略版本和耗时元数据。
- `DELETE /api/v1/events` 在同一事务内删除关联事件并写入回执。
- Fastify 日志脱敏 Authorization、Cookie 和 `x-anonymous-id`；请求正文与上下文不进日志。
- 应用版本统一升级为 `0.4.0`，事件中同时记录风险策略和响应 Prompt 版本。

## 3. 隐私不变量

SQLite `response_events` 只允许以下类型字段：

- 请求 ID 和匿名标识哈希；
- 风险等级、信号码、路由和安全动作；
- 应用、风险策略、Prompt 和模型版本；
- 耗时与创建时间。

自动测试明确禁止 `message`、`message_text`、`context`、`prompt`、`response`、`response_text`、`acknowledgement` 和 `known_facts` 等正文列。

## 4. 验证结果

- SQLite 元数据写入、重启、迁移重入和实时就绪检查通过。
- 导出结果不含原始匿名 UUID 或消息正文。
- 删除返回删除数量和回执 ID；删除后再次导出为空。
- 一个匿名标识的删除不会删除其他标识的数据。
- 真实 Fastify 日志捕获测试中，消息、上下文、Authorization、Cookie 和匿名 UUID 均未出现。
- 使用本机已配置的百炼真实调用完成一次生命周期冒烟：响应 200，导出 1 条且不含原始匿名 UUID，删除回执确认删除 1 条，删除后再次导出为 0 条。
- 完整工程门禁包括 Biome、TypeScript、Vitest 和生产构建。

## 5. 尚未完成与风险

- 浏览器 IndexedDB 结果卡、导出和删除尚未接入服务端链路。
- 尚未在部署环境验证加密备份、备份保留期和从备份中删除的实际流程。
- 尚未在百炼控制台人工确认完整 Prompt/Response 推理日志关闭状态。
- 无登录模式下，掌握匿名 UUID 即可导出或删除关联元数据；公网发布前必须增加更强的会话或身份边界。
- Node.js 24 会对 `node:sqlite` 输出实验性警告。当前用于单实例内测；生产化前需根据目标 Node 版本重新评估稳定性或替换适配器。

## 6. 下一步准入

1. 实现浏览器 IndexedDB 中的用户确认结果卡。
2. 把“导出全部数据”组合为浏览器结果卡 + 服务端元数据。
3. 把“删除全部数据”组合为浏览器清理 + 服务端删除回执。
4. 在部署环境验证备份、保留期、恢复和删除边界。
5. 完成人工隐私验收后，再决定是否进入小范围外部内测。
