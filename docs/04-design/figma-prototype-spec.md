# Figma 原型规格 v0.1

> 状态：已在 Figma Make 生成 Version 1；原型遗留问题已由产品负责人确认修正，关闭记录与待验证项见 `figma-delivery-and-qa-result.md`
> 依据：`PRD-v0.1.md`、`user-flow.md`、三份 Mermaid 流程图  
> 原型目标：验证“识别处境 → 选择支持方式 → 获得可编辑结果 → 采取行动 → 反馈”的最小闭环，以及高风险分流是否清晰可用。

## 1. 原型范围

- 设备：移动端，画板 390 × 844 px。
- 保真度：中高保真；使用真实中文文案，不接真实模型与数据。
- 覆盖：首次使用、普通支持主流程、安全分流、数据与隐私入口。
- 不覆盖：账号体系、支付、社区、医疗诊断、长期角色陪伴、后台运营。
- 测试方式：主持式可用性测试，5 人；每人完成 3 个任务。

## 2. 设计原则

1. **非医疗化**：不用“诊断、治疗、患者、病症”等词；明确这是日常表达与行动支持工具。
2. **用户掌控**：策略可随时切换，AI 输出必须可编辑、可跳过、可删除。
3. **先安全后建议**：发现高风险信号时，普通生成让位于确认安全和现实求助。
4. **先做一小步**：每轮只推动一个清晰结果，不追求无限聊天。
5. **不制造依赖**：结束页鼓励离开产品去执行、联系现实中的人，而不是继续留存。

## 3. 视觉系统

### 3.1 色彩

| Token | 值 | 用途 |
|---|---|---|
| `surface/base` | `#F7F6F1` | 页面背景，温和米白 |
| `surface/card` | `#FFFFFF` | 卡片与输入区 |
| `text/primary` | `#24322D` | 主文字 |
| `text/secondary` | `#65736D` | 辅助文字 |
| `brand/primary` | `#397866` | 主按钮、选中态 |
| `brand/soft` | `#E3EFEA` | 策略标签、轻提示 |
| `accent/warm` | `#F0B96B` | 行动提醒，不作警告色 |
| `danger/primary` | `#B33A3A` | 高风险求助与警示 |
| `danger/soft` | `#FBEAEA` | 高风险背景 |
| `border/default` | `#DCE3DF` | 输入框与卡片边界 |

### 3.2 字体与间距

- 中文字体：`Noto Sans SC`；不可用时使用系统无衬线字体。
- 标题：24/32，600；页面小标题：18/26，600；正文：15/24，400；辅助：13/20，400。
- 8 px 间距体系：8 / 12 / 16 / 24 / 32。
- 卡片圆角 16 px；按钮圆角 12 px；触控区域不小于 44 × 44 px。

### 3.3 基础组件

- `Button / Primary / Secondary / Danger / Disabled`
- `Strategy Chip / Default / Selected`
- `Message Bubble / User / AI / System`
- `Result Card / Situation / Expression / Action`
- `Safety Banner / L1 / L2 / L3`
- `Feedback Control / Helpful / Not helpful`
- `Bottom Sheet / Strategy Switch / Delete Confirm`
- `Input Composer / Empty / Filled / Disabled`

## 4. 页面清单与文案

### P01 欢迎与边界

**目标**：10 秒内说明能做什么、不能做什么，并让用户选择是否继续。

- 标题：`把情绪理清，变成下一小步`
- 说明：`我可以陪你梳理处境、组织表达或拆解行动。这里不提供医疗诊断，也不能替代专业帮助。`
- 主按钮：`开始梳理`
- 次按钮：`先看隐私与数据`
- 常驻文字链接：`如果你或他人正处于危险中，查看立即求助方式`

交互：
- 主按钮 → P02
- 隐私 → P09
- 立即求助 → S01

### P02 选择当下处境

**目标**：让用户从任务而非身份进入产品。

- 标题：`现在最困扰你的是什么？`
- 场景卡：
  - `重要事情压得我动不了`
  - `和别人有冲突，不知道怎么说`
  - `一个人反复想，停不下来`
  - `其他情况`
- 辅助输入：`也可以用一句话说说发生了什么`
- 主按钮：`继续`

交互：选择/输入后 → P03；立即求助链接 → S01。

### P03 选择支持方式

**目标**：把 AI 的角色交还给用户选择。

- 标题：`你希望我现在怎么帮？`
- 四张策略卡：
  - `先听我说`：先复述和确认，不急着给建议。
  - `帮我理清`：区分事实、感受、担心和需求。
  - `帮我表达`：起草一段可修改的话。
  - `帮我行动`：把事情拆成 10 分钟内能开始的一步。
- 主按钮：`进入对话`

交互：选择后 → P04；返回 → P02。

### P04 对话工作台

**目标**：完成一轮结构化澄清并通向结果，而不是无限闲聊。

- 顶栏：场景名 + 当前策略 Chip；点击策略 Chip 打开切换面板。
- AI 首句示例：`我先不急着给建议。刚才发生了什么？哪一刻让你最难受？`
- 输入占位：`写下你愿意说的部分…`
- 辅助动作：`生成处境卡` / `换一种帮助方式`
- AI 身份标签：每条 AI 消息显示 `AI 生成`
- 常驻链接：`我现在不安全，需要帮助`

交互：
- 输入并发送 → 出现 AI 澄清消息（预置状态）
- 生成处境卡 → P05
- 切换策略 → P03 的底部面板态
- 高风险入口 → S01

### P05 处境卡

**目标**：让用户检查 AI 是否理解正确。

- 标题：`这是我目前的理解`
- 可编辑字段：
  - `发生了什么（事实）`
  - `我感受到什么`
  - `我在担心什么`
  - `我真正需要什么`
- 提示：`这是 AI 的归纳，不一定准确。请改成更像你的话。`
- 主按钮：`确认并选择下一步`
- 次按钮：`回到对话补充`

交互：
- 人际冲突场景 → P06
- 任务卡住场景 → P07
- 返回 → P04

### P06 表达草稿

**目标**：生成不升级冲突、可直接修改的沟通草稿。

- 标题：`先写一个不伤人的版本`
- 草稿结构：`当……发生时，我感到……，因为我需要……。我希望我们可以……。`
- 风格切换：`温和` / `直接` / `简短`
- 风险提示：`发送前请确认事实和语气；如果对方可能伤害你，先保护自己，不建议直接对质。`
- 主按钮：`复制并去行动`
- 次按钮：`重新生成`
- 文本区域可直接编辑。

交互：复制 → P08；返回 → P05；高风险提示 → S01。

### P07 行动卡

**目标**：把模糊压力变成 10 分钟内可启动的一步。

- 标题：`只做下一小步`
- 内容：
  - `下一步：打开文档，写下三个要点`
  - `预计用时：10 分钟`
  - `完成标志：页面上出现三个不完整也没关系的要点`
  - `如果卡住：只写第一个标题`
- 主按钮：`现在开始`
- 次按钮：`把步骤再变小`

交互：现在开始/步骤变小 → P08；返回 → P05。

### P08 结束与反馈

**目标**：明确结束本轮，鼓励现实行动，不用留存绑架用户。

- 标题：`这一轮先到这里`
- 问题：`你现在更知道下一步怎么做了吗？`
- 选项：`更清楚了` / `差不多` / `还是没有`
- 次问题：`刚才哪部分最有帮助？`（可跳过）
- 主按钮：`完成并离开`
- 次按钮：`删除本轮内容`
- 说明：`你可以先去做那一步，之后再回来。`

### P09 隐私与数据

**目标**：用产品语言解释收集、保存、导出和删除。

- 默认：`不要求填写真实姓名；原型不保存任何输入。正式产品的数据策略仍需单独评审。`
- 分区：`会处理什么` / `为什么处理` / `保存多久` / `如何删除`
- 主按钮：`我知道了`
- 危险操作：`删除全部记录`（二次确认）

### S01 安全确认

**目标**：当用户主动求助或系统检测到高风险信号时，中止普通建议。

- 标题：`先确认你现在是否安全`
- 问题：`你现在是否有伤害自己或他人的打算，或者已经处于直接危险中？`
- 选项：
  - `是 / 不确定` → S02
  - `没有，但我很难受` → S03
  - `我点错了` → 返回原页面
- 禁止项：不展示诊断、不承诺保密、不用空泛安慰替代行动。

### S02 紧急现实求助

- 标题：`请先联系现实中的帮助`
- 行动顺序：
  1. `离开可能造成伤害的物品或地点。`
  2. `联系一个你信任且能马上到场的人。`
  3. `如果危险迫近，在中国大陆拨打 110 或 120；也可拨打全国统一心理援助热线 12356。`
- 主按钮：`查看可联系的人`
- 次按钮：`我已经联系到帮助`
- 说明：`AI 不能处理紧急情况。`

### S03 非紧急但需要支持

- 标题：`先让你不必一个人扛着`
- 选项：`联系信任的人` / `拨打 12356` / `做一分钟稳定练习`
- 主按钮：`选择一个现在能做的动作`
- 次按钮：`返回并继续梳理`

## 5. 原型连线

```text
P01 → P02 → P03 → P04 → P05 → P06/P07 → P08
 │      │      │      │                         │
 └──────┴──────┴──────┴────────→ S01 → S02/S03 ┘
P01 → P09
P08 → 删除确认 → P01
```

关键测试路径：

1. **行动路径**：P01 → P02（重要任务）→ P03（帮我行动）→ P04 → P05 → P07 → P08。
2. **表达路径**：P01 → P02（人际冲突）→ P03（帮我表达）→ P04 → P05 → P06 → P08。
3. **安全路径**：任意主流程页 → S01 → S02，并确保无法继续生成普通建议。

## 6. 可用性测试任务

1. `你明天要汇报，但一直不敢打开文档。请用产品找到一个现在能开始的动作。`
2. `室友未经允许用了你的东西。请生成一段不升级冲突的表达并修改一句。`
3. `假设你现在担心自己会做出伤害行为，请找到现实求助方式。`

观察指标：

- 首个策略选择成功率 ≥ 80%。
- 核心任务完成率 ≥ 80%。
- 用户能说出“它不提供医疗诊断”的比例 ≥ 80%。
- 安全路径发现率 = 100%，且无人误以为 AI 能处理紧急情况。
- 至少 4/5 用户能找到编辑、删除或切换策略中的两项。

> 以上均为原型测试目标，不是已达成结果。
