# Figma 原型 QA 清单

> 使用方式：Figma 完成后逐项勾选；未通过项必须记录问题与修正结果。

## A. 范围与一致性

- [ ] 页面覆盖 P01–P09、S01–S03。
- [ ] 页面名称、入口和跳转与 `figma-prototype-spec.md` 一致。
- [ ] 四种支持策略与 PRD 一致：先听我说、帮我理清、帮我表达、帮我行动。
- [ ] 处境卡字段与 PRD 的结构化输出一致。
- [ ] 原型没有出现“诊断、治疗有效、24 小时在线”等未经证实的承诺。

## B. 交互

- [ ] 行动路径从 P01 到 P08 可完整点击。
- [ ] 表达路径从 P01 到 P08 可完整点击。
- [ ] P04 可以切换支持策略。
- [ ] 处境卡和表达草稿在视觉上明确为“可编辑”。
- [ ] P08 的删除动作有二次确认。
- [ ] 返回路径不会进入死循环或断页。

## C. 安全

- [ ] P01、P02、P04 至少有一个可见的主动求助入口。
- [ ] S01 的“是 / 不确定”只进入 S02，不回到普通生成。
- [ ] S02 清晰展示 110、120、12356，并说明 AI 不能处理紧急情况。
- [ ] 未把 12356 描述为所有地区全天 24 小时服务。
- [ ] 冲突草稿包含事实与语气复核，以及潜在暴力场景不建议直接对质的提示。
- [ ] 安全提醒不使用责备、恐吓或诊断式语气。

## D. 隐私与用户掌控

- [ ] P09 说明数据处理目的、保存与删除入口。
- [ ] 原型明确“不要求真实姓名”；不索取身份证、地址等无关信息。
- [ ] AI 内容带有 `AI 生成` 标识。
- [ ] 用户可以跳过、返回、编辑、删除、结束本轮。
- [ ] 结束页鼓励现实行动，不诱导持续聊天。

## E. 视觉与可访问性

- [ ] 文本与背景对比度目测清晰，危险状态不只依赖颜色表达。
- [ ] 正文字号不小于 15 px，辅助文字不小于 13 px。
- [ ] 主要触控区域不小于 44 × 44 px。
- [ ] 同级按钮层级一致；危险操作不会被误认为主操作。
- [ ] 390 × 844 画板内无关键文字截断或遮挡。
- [ ] 预览模式逐页截图检查通过。
