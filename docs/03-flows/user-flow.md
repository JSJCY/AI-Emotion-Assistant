# 用户流程说明

> 版本：v0.1  
> 日期：2026-09-21  
> 状态：与 PRD v0.1 同步

## 1. 流程文件

- [主任务流](./main-flow.mmd)：从首次进入到产生结果卡和结束会话。
- [安全分流](./safety-flow.mmd)：L0–L3 分级、普通流中断和现实求助。
- [数据与删除流](./data-and-deletion-flow.mmd)：临时会话、保存、导出与删除。

这些文件使用 Mermaid flowchart 语法，可直接粘贴到支持 Mermaid 的文档工具中渲染。Figma 原型以相同节点 ID 命名，便于从流程追踪到页面。

## 2. 页面与节点映射

| 节点 | 页面/状态 | 关键任务 |
|---|---|---|
| P01 | 欢迎与边界 | 理解 AI 身份、18+、非医疗和临时会话默认 |
| P02 | 开始页 | 自由输入或选择 S1/S2/S3 场景 |
| P03 | 策略建议 | 选择倾听、理清、表达或起步 |
| P04 | 对话页 | 进行结构化对话、切换策略、查看帮助 |
| P05 | 情境卡 | 核对事实、感受、猜测和可控部分 |
| P06 | 沟通草稿 | 编辑语气和内容，再复制 |
| P07 | 行动卡 | 确认 5–15 分钟动作或缩小动作 |

| P09 | 隐私与数据 | 查看、导出和删除 |
| S01 | L1 支持提示 | 普通支持加专业资源入口 |

| S03 | L3 紧急行动 | 110/120、联系可信任人、移动到安全位置 |

## 3. 主流程规则

1. 首次使用必须经过 P01；返回用户可从 P02 开始，但 AI 身份和帮助入口仍持续可见。
2. 用户可以先输入再由系统推荐策略，也可以直接选策略；最终控制权始终属于用户。
3. P04 每轮最多一个主要问题，关键节点可随时切换策略。
4. P05/P06/P07 都是可编辑产物，不把模型文本直接当成用户认可的事实。
5. 会话成功不等于消息多；达到一个用户确认的结果卡即可自然结束。
6. 任何节点触发 L2/L3 时，立即离开普通任务流并进入安全分流。

## 4. 异常与恢复

| 异常 | 用户看到什么 | 恢复方式 |
|---|---|---|
| 模型超时 | “暂时没生成出来，你的文字还在” | 原输入保留，可重试或改为本地记录 |
| 结构化输出无效 | 不显示原始模型内容 | 服务端重试一次；仍失败则给通用安全提示 |
| 网络中断 | 离线提示和未发送草稿 | 恢复网络后由用户主动重发 |
| 策略不匹配 | “不对路，换种方式” | 保留上下文并切换策略 |
| 用户不想继续 | 固定可见的结束入口 | 直接进入 P08，不要求解释 |
| 删除失败 | 明确说明尚未删除成功 | 不给虚假成功提示；提供重试和错误编号 |

## 5. 原型测试任务

1. 第一次进入后，用“明天要汇报但完全开始不了”开启一次会话，找到“陪我起步”，生成并缩小行动卡。
2. 用“和同事发生冲突，不知道怎么回复”进入表达流程，编辑草稿后复制。
3. 在 AI 理解错误时找到“不对路”，切换为“先听我说”。
4. 结束会话，只保存结果卡，不保存完整对话。
5. 从数据页删除已保存结果，确认不可从普通界面恢复。
6. 在安全演示场景中找到首要现实求助按钮，并说出 AI 的能力边界。
