# Changelog

## 0.4.0 — 2026-09-22

### Added

- Node.js `node:sqlite` 事件仓库，支持 WAL、版本化迁移和实时就绪探测。
- 只包含请求 ID、风险类别、路由、安全动作、版本与耗时的无正文事件 Schema。
- `x-anonymous-id` 的 SHA-256 哈希归属，原始 UUID 不进入数据库。
- 元数据导出接口、事务性删除和删除回执。
- 日志脱敏配置和正文/凭据/匿名标识不落日志的自动测试。

### Verified

- SQLite 迁移可重入，数据库重启后仍可用。
- 导出不含原始匿名 ID 或消息正文；删除后再次导出为空，其他匿名标识的数据不受影响。
- 本机真实百炼请求完成“响应—导出—删除回执—删除后空导出”全链路冒烟。
- 人工盲评已完成：加权均分 96.18/100，P0 为 0，7 条分歧全部复核。

## 0.3.0 — 2026-09-21

### Changed

- 风险分类从 `qwen3.7-flash-2026-07-15` 切换为经真实评测验证的 `qwen3.7-plus-2026-05-26`。
- 生成温度固定为 0，提高安全敏感回归的可复现性。
- 风险分类策略升级为 `risk-policy-v0.2`，拆分人身安全危机与内容政策拒绝。
- 评测集版本化升级至 v0.3，并记录全部标签变更原因。
- 输出审计支持否定/替代语境和字段分级，仍拦截可执行操控、羞辱与隐私扩张。
- 评测报告分别统计 Schema、输出审计、高风险召回、L0 危机误升级、红队与 P0。

### Verified

- 北京业务空间专属端点、API Key、严格 JSON Schema 和真实模型调用。
- 三轮 60 条固定配置复跑均为高风险 20/20、L0 危机误升级 0/22、红队 6/6、P0 为 0。
- 路由匹配为 59/60、60/60、60/60；该阶段结束时人工语义评分待完成，后续已在 0.4.0 前完成。

## 0.2.0 — 2026-09-21

### Added

- 北京工作区专属百炼 OpenAI 兼容 HTTP 客户端。
- 12 秒超时、最多一次有限重试和供应商错误清洗。
- `qwen3.7-flash-2026-07-15` 独立风险分类适配器。
- `qwen3.7-plus-2026-05-26` 严格 JSON Schema 生成适配器。
- 确定性输出审核与运行时 Zod 二次校验。
- 本地 `.env` 加载、启动配置校验和真实模型冒烟脚本。
- 60 条测试集真实模型 runner；报告默认写入 Git 忽略目录。

### Not yet verified

- 真实百炼账号的连通性、模型权限、响应兼容性、延迟和费用。
- SQLite 无正文事件存储与完整 `/ready` 状态。
